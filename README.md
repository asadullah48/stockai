## 🚀 Key Features

1. **Specialized Supply Chain Agents**:
   - **`MonitorAgent`**: Real-time SKU tracking and stockout risk velocity.
   - **`ForecastAgent`**: 30-day time-series demand forecasting with seasonal multipliers.
   - **`OrderAgent`**: Automated Purchase Order (PO) generation and vendor email composition.
2. **SME Efficiency**: Eradicates stockouts and prevents cash lockup in excess holding stock.
3. **Interactive Studio**: Dark cyber-glassmorphic bilingual (English/Arabic RTL) dashboard with live SKU editor and draft PO viewer.
